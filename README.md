# Cybersecurity Labs

A collection of hands-on cybersecurity laboratories developed in controlled and authorized environments.

The purpose of this repository is to document my practical learning in cybersecurity, including network analysis, web security, offensive security techniques, defensive monitoring, vulnerability assessment, and security hardening.

## Laboratory Environment

The laboratories documented here are performed using isolated virtual machines and systems owned and controlled by the author.

Typical environments include:

- Kali Linux attacker/testing machines
- Debian/Linux target systems
- VirtualBox isolated networks
- Burp Suite
- Wireshark
- Nmap
- Custom security tools

## Repository Structure

Each laboratory contains its own documentation and may include:

- Lab objective
- Network topology
- Environment configuration
- Step-by-step procedure
- Screenshots
- Sanitized logs
- Technical analysis
- Detection methods
- Mitigation and hardening
- Conclusions

## Security and Privacy

Sensitive information is intentionally excluded from this repository.

This includes:

- Real credentials
- Passwords
- Authentication tokens
- Session cookies
- Private keys
- Personal information
- Public targets tested without explicit authorization
- Raw captures containing sensitive information
- Unreviewed configuration files or logs

All evidence is reviewed and sanitized before publication.

## Ethical Use

All security testing documented in this repository is performed exclusively in controlled and authorized laboratory environments.

The techniques and tools documented here are intended for cybersecurity education, defensive research, and the development of practical security skills.

No testing documented in this repository should be interpreted as authorization to perform the same activities against third-party systems.
